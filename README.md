# Faraz Portfolio

A simple responsive portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Open this folder in VS Code, or open `index.html` directly in your browser.
2. For live reload, use the VS Code Live Server extension.

## Customize
- Replace `Faraz Ahmed` and the About section with your preferred details.
- Change `your.email@example.com` in `index.html` to your email address.
- Add real project descriptions and repository links before publishing.
